### 3. Fix `shared:test-support` (task 0.9)

**File**: `shared/test-support/src/main/java/io/cartogra/test/PostgresTestSupport.java`

**Problems**:

2. No `.withReuse(true)` — slows down test suites (KafkaTestSupport uses reuse)

```java
            .withDatabaseName("cartogra_test")
            .withUsername("cartogra")
            .withPassword("cartogra")

}
```

### 4. Harden `services:registry` (task 0.10)

**Current state**: Virtual threads ✓, Flyway ✓, Spring Data JDBC ✓, health probes ✓, OTel ✓,
`PingController` ✓. `GlobalExceptionHandler` covers only `IllegalArgumentException` and `Exception`.

**File**: `services/registry/src/main/java/io/cartogra/registry/api/GlobalExceptionHandler.java`

**Add two handlers** (import `MethodArgumentNotValidException`, `ConstraintViolationException`,
`NoSuchElementException`):

```java
@ExceptionHandler(MethodArgumentNotValidException.class)
public ResponseEntity<ApiErrorResponse> handleValidation(MethodArgumentNotValidException ex) {
    String traceId = Span.current().getSpanContext().getTraceId();
    Map<String, Object> details = ex.getBindingResult().getFieldErrors().stream()
            .collect(Collectors.toMap(FieldError::getField, FieldError::getDefaultMessage, (a, _) -> a));
    return ResponseEntity.badRequest()
            .header("X-Trace-Id", traceId)
            .body(new ApiErrorResponse(new ApiError(ErrorCodes.VALIDATION_ERROR,
                    "Validation failed", details), traceId));
}

@ExceptionHandler(NoSuchElementException.class)
public ResponseEntity<ApiErrorResponse> handleNotFound(NoSuchElementException ex) {
    String traceId = Span.current().getSpanContext().getTraceId();
    return ResponseEntity.status(HttpStatus.NOT_FOUND)
            .header("X-Trace-Id", traceId)
            .body(new ApiErrorResponse(ApiError.of(ErrorCodes.NOT_FOUND, ex.getMessage()), traceId));
}
```

Also update the existing `handleIllegalArgument` to use `ErrorCodes.BAD_REQUEST` and `handleGeneral` to
use `ErrorCodes.INTERNAL_ERROR`.

**Verification**: `./gradlew :services:registry:test`

### 5. Harden `services:gateway` (task 0.11)

**Current state**: Virtual threads ✓, OTel ✓. `GlobalTracingFilter` has a rule violation: it manually
creates a new `Span` rather than reading the span that OTel auto-instrumentation already creates from the
inbound `traceparent`. This means inbound W3C context is ignored and the gateway generates orphaned spans.

**Fix `GlobalTracingFilter`**:
- Remove all `tracer`, `span`, and `Scope` usage
- Remove the `Tracer` constructor parameter
- Simply read `Span.current()` (which OTel auto-instrumentation populates from the inbound `traceparent`)
  and set `X-Trace-Id`

```java
@Component
public class GlobalTracingFilter implements GlobalFilter, Ordered {

    @Override
    public Mono<Void> filter(ServerWebExchange exchange, GatewayFilterChain chain) {
        String traceId = Span.current().getSpanContext().getTraceId();
        exchange.getResponse().getHeaders().set("X-Trace-Id", traceId);
        return chain.filter(exchange);
    }

    @Override
    public int getOrder() { return Ordered.HIGHEST_PRECEDENCE; }
}
```

Note: OTel's `spring-boot-starter-opentelemetry` auto-instruments Spring Cloud Gateway (WebFlux): it
extracts `traceparent` from inbound requests, creates server spans, and propagates context to downstream
routes via the reactive pipeline. The manual span creation was both wrong and redundant.

**Add WebFlux error handler** (`GlobalWebExceptionHandler.java` in `services/gateway/src/main/java/io/cartogra/gateway/config/`):

Gateway uses WebFlux, so use `ErrorWebExceptionHandler` instead of `@RestControllerAdvice`:

```java
@Component
@Order(Ordered.HIGHEST_PRECEDENCE)
public class GlobalWebExceptionHandler implements ErrorWebExceptionHandler {

    private final ObjectMapper objectMapper;

    public GlobalWebExceptionHandler(ObjectMapper objectMapper) {
        this.objectMapper = objectMapper;
    }

    @Override
    public Mono<Void> handle(ServerWebExchange exchange, Throwable ex) {
        HttpStatus status = ex instanceof ResponseStatusException rse
                ? HttpStatus.valueOf(rse.getStatusCode().value())
                : HttpStatus.INTERNAL_SERVER_ERROR;
        String code   = status == HttpStatus.INTERNAL_SERVER_ERROR ? ErrorCodes.INTERNAL_ERROR : ErrorCodes.BAD_REQUEST;
        String msg    = status == HttpStatus.INTERNAL_SERVER_ERROR ? "An unexpected error occurred" : ex.getMessage();
        String traceId = Span.current().getSpanContext().getTraceId();

        ApiErrorResponse body = new ApiErrorResponse(ApiError.of(code, msg), traceId);
        exchange.getResponse().setStatusCode(status);
        exchange.getResponse().getHeaders().set("X-Trace-Id", traceId);
        exchange.getResponse().getHeaders().setContentType(MediaType.APPLICATION_JSON);

        try {
            byte[] bytes = objectMapper.writeValueAsBytes(body);
            DataBuffer buffer = exchange.getResponse().bufferFactory().wrap(bytes);
            return exchange.getResponse().writeWith(Mono.just(buffer));
        } catch (JsonProcessingException e) {
            return Mono.error(e);
        }
    }
}
```

### 7. Add envelope contract integration test (task 0.13)

The `PingController` in registry already returns the correct envelope. Add a dedicated integration test to
formally verify the contract.

**File to create**: `services/registry/src/test/java/io/cartogra/registry/EnvelopeContractIT.java`

```java
@SpringBootTest(webEnvironment = SpringBootTest.WebEnvironment.RANDOM_PORT)
@AutoConfigureTestRestTemplate
@Testcontainers
class EnvelopeContractIT {

    @Container
    static PostgreSQLContainer<?> postgres = PostgresTestSupport.POSTGRES;

    @DynamicPropertySource
    static void datasource(DynamicPropertyRegistry r) {
        r.add("spring.datasource.url", postgres::getJdbcUrl);
        r.add("spring.datasource.username", postgres::getUsername);
        r.add("spring.datasource.password", postgres::getPassword);
    }

    @Autowired TestRestTemplate http;

    @Test
    void pingReturnsEnvelopeAndTraceIdHeader() {
        ResponseEntity<Map> resp = http.getForEntity("/api/v1/ping", Map.class);

        assertThat(resp.getStatusCode()).isEqualTo(HttpStatus.OK);
        assertThat(resp.getBody()).containsKey("data");
        assertThat(resp.getBody()).containsKey("traceId");
        assertThat(resp.getHeaders().getFirst("X-Trace-Id")).isNotBlank();
    }
}
```

**Verification**: `./gradlew :services:registry:test --tests "*EnvelopeContractIT*"`
