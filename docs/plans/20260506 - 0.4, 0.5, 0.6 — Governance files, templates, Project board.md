## Task 0.6 — GitHub Project board

This is a GitHub API operation (no file changes). Use `gh` CLI:

1. **Create the Project (Projects v2):**
   ```bash
   gh project create --owner @me --title "Cartogra Roadmap"
   ```

2. **Add a "Phase" single-select field** with values: Phase 0, Phase 1, Phase 2, Phase 3, Phase 4, Phase 5, Backlog, Done.

3. **Create one milestone per phase** on the linked repo:
   ```bash
   gh api repos/{owner}/{repo}/milestones -f title="Phase 0 — Foundation" -f description="..."
   # repeat for Phases 1-5
   ```

4. **Document the project board URL** in README.md (or CONTRIBUTING.md) once created.

> Note: `gh project` commands require the repo to have a GitHub remote. Confirm the remote exists (`git remote -v`) before running. The project board is org/user-level, not repo-level — use `--owner` matching the GitHub account.
