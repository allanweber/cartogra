## Step 2 — Create FlywayMigrationSmokeTest.java

**New file**: `services/registry/src/test/java/io/cartogra/registry/FlywayMigrationSmokeTest.java`

### Design decisions

- Follows the existing `ActuatorHealthIntegrationTest` pattern: static `PostgreSQLContainer` + `@DynamicPropertySource`.
- Uses `PostgresTestSupport.create()` from `shared:test-support` (already on the test classpath via `build.gradle.kts`).
- `@SpringBootTest(webEnvironment = RANDOM_PORT)` — matches project convention; no new dependencies required.
- **Does NOT set `spring.flyway.enabled=false`** — Flyway must actually run so failures surface immediately.
- Appends `?currentSchema=registry` to the container JDBC URL so `JdbcTemplate` queries resolve against the `registry` schema (mirrors the production URL in `application.yml`).
- The `application.yml` Flyway settings (`schemas: registry`, `create-schemas: true`, `table: flyway_schema_history`) are inherited automatically — no additional `@DynamicPropertySource` entries are needed for Flyway.
- Injects `JdbcTemplate` to run post-migration assertions.

### Assertions

1. **`allMigrationsApplyCleanly`** — queries `flyway_schema_history` for successful rows; asserts exactly 4. If any migration fails or is skipped, the Spring context fails to start (test fails before reaching assertions).
2. **`tenantsTableExists`** / **`teamsTableExists`** / **`usersTableExists`** / **`scmConnectionsTableExists`** — each queries `information_schema.tables` for `table_schema = 'registry'` and the expected table name, asserting count = 1.

### Implementation

```java
package io.cartogra.registry;

import io.cartogra.test.PostgresTestSupport;
import org.junit.jupiter.api.Test;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.boot.test.context.SpringBootTest;
import org.springframework.jdbc.core.JdbcTemplate;
import org.springframework.test.context.DynamicPropertyRegistry;
import org.springframework.test.context.DynamicPropertySource;
import org.testcontainers.containers.PostgreSQLContainer;

import static org.assertj.core.api.Assertions.assertThat;

@SpringBootTest(webEnvironment = SpringBootTest.WebEnvironment.RANDOM_PORT)
class FlywayMigrationSmokeTest {

    private static final PostgreSQLContainer<?> POSTGRES = PostgresTestSupport.create();

    static {
        POSTGRES.start();
    }

    @DynamicPropertySource
    static void datasourceProperties(DynamicPropertyRegistry registry) {
        registry.add("spring.datasource.url",
                () -> POSTGRES.getJdbcUrl() + "?currentSchema=registry");
        registry.add("spring.datasource.username", POSTGRES::getUsername);
        registry.add("spring.datasource.password", POSTGRES::getPassword);
    }

    @Autowired
    private JdbcTemplate jdbcTemplate;

    @Test
    void allMigrationsApplyCleanly() {
        Integer count = jdbcTemplate.queryForObject(
                "SELECT COUNT(*) FROM flyway_schema_history WHERE success = true",
                Integer.class);
        assertThat(count).isEqualTo(4);
    }

    @Test
    void tenantsTableExists() {
        assertTableExists("tenants");
    }

    @Test
    void teamsTableExists() {
        assertTableExists("teams");
    }

    @Test
    void usersTableExists() {
        assertTableExists("users");
    }

    @Test
    void scmConnectionsTableExists() {
        assertTableExists("scm_connections");
    }

    private void assertTableExists(String tableName) {
        Integer count = jdbcTemplate.queryForObject(
                "SELECT COUNT(*) FROM information_schema.tables " +
                "WHERE table_schema = 'registry' AND table_name = ?",
                Integer.class, tableName);
        assertThat(count).isEqualTo(1);
    }
}
```

No changes to `build.gradle.kts` — `shared:test-support`, `spring-boot-starter-test`, and `testcontainers-postgresql` are already declared.
