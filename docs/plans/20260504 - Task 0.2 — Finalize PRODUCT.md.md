# Plan: Task 0.2 — Finalize PRODUCT.md

## Context

`PRODUCT.md` already exists at the repo root with five of the six required sections already in good shape: Users, Product Purpose, Brand Personality, Anti-references, Design Principles, and Accessibility.

Two things are missing:

1. The **`## Register`** section contains only the placeholder text `product`. This is the top-level product identity entry — a brief descriptor that anchors every other section.
2. There is **no per-phase screen inventory** anywhere in the file. The checklist explicitly requires it and it is what `/shape` and `/impeccable craft` commands will consult when crafting and auditing screens phase by phase.

No new file needs to be created. This is a targeted patch to the existing `PRODUCT.md`.
