## LinkedIn (~200 words)

**Cartogra Phase 0 — Foundation complete**

The first milestone of Cartogra is done.

Phase 0 covers the platform foundation: API Gateway (JWT auth, tenant isolation, rate limiting via Redis), Registry service (service CRUD, team ownership, API contract storage), and Ingestion service (GitHub webhook receiver, Kubernetes watch, SCM polling). PostgreSQL with Flyway migrations. Apache Kafka for async event propagation. OpenTelemetry tracing across all three services with W3C traceparent propagation through HTTP calls, gRPC, and Kafka message headers.

The architecture diagram is now in the README — seven services mapped out, two databases, Kafka in the middle. The diagram is the system: when the architecture changes, the diagram changes first.

All implementation decisions are documented in Architecture Decision Records. The project board tracks the milestone publicly.

Phase 1 opens next: the frontend layer. TanStack Start application, D3 dependency graph visualisation, service catalog UI.

Everything is built in public. If you are interested in platform engineering, service catalogs, or just how a multi-tenant SaaS gets built from scratch, the repo and all documentation are open.

→ github.com/allancassiano/cartogra
